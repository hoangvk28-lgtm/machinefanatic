# MachineFanatic portable generator cluster

This package contains ten plain HTML article files in the requested publication order.

1. `running-watts-vs-starting-watts.html`
2. `what-size-generator-to-run-a-house.html`
3. `inverter-generator-vs-conventional-generator.html`
4. `how-to-size-a-generator-by-wattage.html`
5. `dual-fuel-generator-pros-and-cons.html`
6. `tri-fuel-and-propane-generator-explained.html`
7. `generator-carbon-monoxide-safety.html`
8. `how-to-safely-connect-a-generator-to-a-house.html`
9. `generator-thd-and-sensitive-electronics.html`
10. `how-long-will-a-generator-run-on-a-tank.html`

`image-manifests-and-delivery-reports.md` contains the image download manifest and the required four line report for every article.

Each HTML file begins with the fixed metadata comment and contains body HTML only. No document wrapper, H1, table of contents, byline, date line, or inline image credit is included.
